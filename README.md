# CCA·F Study Guide

A free, static study guide for the **Anthropic Claude Certified Architect (Foundations)** exam.

## Features

- 📖 **Curriculum** — Deep lessons across all 5 exam domains
- 🎯 **Mock Exam** — 60-question timed exam weighted by real domain proportions
- 🔁 **Drill Mode** — Spaced repetition flashcards (SM-2 algorithm, localStorage)
- 📊 **Diagnostic Test** — 25-question gap analysis with personalized study plan
- 💡 **160+ Questions** — Covering all CCA·F exam domains with explanations

## Exam Domains

| Domain | Exam Weight |
|--------|-------------|
| 🤖 Agentic Architecture | 27% |
| ⚙️ Claude Code Configuration | 20% |
| ✍️ Prompt Engineering | 20% |
| 🔧 Tool Design & MCP | 18% |
| 📚 Context Management | 15% |

## Tech Stack

Plain HTML + CSS + JavaScript — no framework, no build step, no dependencies.  
Works directly from the filesystem or any static host.

## Local Usage

Just open `index.html` in your browser — no server required.
